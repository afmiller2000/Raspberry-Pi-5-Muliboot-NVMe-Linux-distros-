# Raspberry Pi Firmware Files

This directory contains firmware files downloaded from the official Raspberry Pi firmware repository.

## How to Obtain

Run the acquire.sh script:
```bash
./scripts/acquire.sh
```

This will automatically download the required firmware files from:
https://github.com/raspberrypi/firmware/raw/master/boot

## Required Files

The following files are needed for Raspberry Pi 5 to boot:

- **start4.elf** - Main GPU firmware
- **start4x.elf** - Extended GPU firmware (for cut-down mode)
- **start4cd.elf** - Cut-down GPU firmware
- **start4db.elf** - Debug GPU firmware
- **fixup4.dat** - Memory split fixup data
- **fixup4x.dat** - Extended memory split fixup
- **fixup4cd.dat** - Cut-down memory split fixup
- **fixup4db.dat** - Debug memory split fixup
- **bootcode.bin** - Bootloader (older Pi models)
- **bcm2711-rpi-4-b.dtb** - Device tree blob for Pi 4
- **bcm2711-rpi-400.dtb** - Device tree blob for Pi 400
- **bcm2711-rpi-cm4.dtb** - Device tree blob for Compute Module 4

## Configuration Files

- **config.txt** - Raspberry Pi configuration (generated by acquire.sh)
- **cmdline.txt.template** - Kernel command line template

## Updates

To update firmware files:
```bash
rm -f artifacts/firmware/*.elf artifacts/firmware/*.dat artifacts/firmware/*.bin artifacts/firmware/*.dtb
./scripts/acquire.sh
```

## Note

These files are NOT tracked in git due to their large size. They are downloaded automatically by the acquire.sh script.
